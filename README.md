# Homebrew tap

```bash
brew install jairoFernandez/tap/litek8s
```

| Formula | What |
|---|---|
| `litek8s` | [litek8s](https://github.com/jairoFernandez/litek8s): a lightweight Kubernetes in one binary (macOS arm64, Linux x86_64 and aarch64) |

`Formula/litek8s.rb` is generated by `bin/update-litek8s` from the release's
`SHA256SUMS`; the `update-litek8s` workflow refreshes it every three hours
and installs it on macOS and Linux.
